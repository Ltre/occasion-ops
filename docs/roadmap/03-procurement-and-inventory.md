# 采购、供应商与物料

## 1. 目标

建立从需求提出到采购结算、从物料到货到最终去向的完整闭环，支持多人分工、临时采购、直接送现场、退货退款和租借归还等复杂场景。

## 2. 核心问题

- 采购不是由一个人从头做到尾；
- 需求、审批、付款、收货和验收可能分散在不同人员；
- 临时采购人可能不是正式活动成员；
- 物料可能直接送往厨房、舞台或施工区域；
- 数量可能临时增加、减少或替换；
- 商家报价、实际交付和最终结算不一致；
- 同一采购可能包含消耗品、租赁品和可长期保留资产；
- 活动结束后需要处理剩余、退货、借还、损坏和押金。

## 3. 核心对象

### PurchaseRequest（采购需求）

记录需要什么、为什么需要、希望何时到位、用于哪个区域或任务。

建议字段：

- 需求人；
- 物料或服务；
- 数量和规格；
- 用途；
- 优先级；
- 期望到达时间；
- 预算或限额；
- 关联任务、区域或事件；
- 状态。

### Quote（报价）

允许一个需求对应多个商家报价，并保留：

- 商家；
- 单价、总价；
- 规格；
- 交付时间；
- 运费；
- 订金、尾款和押金；
- 有效期；
- 图片、聊天记录或报价单。

### PurchaseOrder（采购订单）

记录最终选择和承诺，不要求必须是正式合同。

应支持：

- 一个订单包含多个项目；
- 临时增项或减项；
- 多次付款；
- 多次到货；
- 部分退货；
- 订单与个人垫付关联。

### Receipt（收货与验收）

需要区分：

- 已送达；
- 已清点；
- 已验收；
- 部分到货；
- 数量差异；
- 质量异常；
- 直接交付到使用区域。

### MaterialItem / MaterialBatch（物料与批次）

对于可计数、可追踪或需要归还的物料，应建立批次或实例记录。

分类建议：

- 消耗品；
- 可回收用品；
- 租赁物；
- 借入物；
- 工具；
- 长期资产；
- 服务项目。

### StockMovement（物料移动）

包括：

- 入库；
- 领用；
- 分发；
- 调拨；
- 退回；
- 借出；
- 归还；
- 消耗；
- 损坏；
- 遗失；
- 处置。

## 4. 多人采购流程

建议完整流程：

```text
提出需求
  → 确认必要性和优先级
  → 询价或直接采购
  → 选择商家
  → 确认预算或审批
  → 下单
  → 支付订金、货款或由个人垫付
  → 到货
  → 收货与验收
  → 入库、分发或直接使用
  → 退货、补货或差异处理
  → 尾款、退款或押金结算
  → 剩余物料处置
```

每一步都允许不同责任人完成，并保留实际操作人与记录人。

## 5. 采购状态

建议需求状态：

- 草稿；
- 待确认；
- 待采购；
- 采购中；
- 已下单；
- 部分到货；
- 已到货；
- 已取消；
- 已关闭。

建议订单状态：

- 待确认；
- 已确认；
- 部分付款；
- 已付款；
- 部分交付；
- 已交付；
- 有异常；
- 结算中；
- 已结清；
- 已取消。

## 6. 物料位置和数量规则

- 每次入库、领用和调拨必须有来源和目标位置；
- 调拨只改变位置数量，不改变活动总数量；
- 消耗、损坏、遗失和处置才减少可用总量；
- 租赁和借入物必须有应归还数量和截止时间；
- 允许“直接到使用点”，不强制经过中央仓库；
- 允许未知数量或估算数量暂存，但必须进入待确认；
- 对重量、长度、箱、包、套等单位建立统一换算或禁止混算规则。

## 7. 商家管理

商家档案至少包括：

- 名称、联系人和电话；
- 服务类别；
- 历史报价和订单；
- 收款账户；
- 到场和履约记录；
- 异常、投诉和评价；
- 订金、尾款、押金和退款状态。

首期不必做完整 CRM，但必须允许同一商家参与多个采购或服务事项。

## 8. 异常场景

- 到货数量少于订单；
- 商家送错规格；
- 物料已付款但未到货；
- 先到货后补订单；
- 临时人员买完后只上传一张小票；
- 同一物料由多个采购人分别购买；
- 部分物料退货，退款退到其他人的账户；
- 租赁物损坏导致押金扣除；
- 剩余物料被赠送、转卖或带回；
- 实际库存与系统数量不一致。

## 9. 管理视图

- 待采购需求；
- 采购中和临近到货事项；
- 已付款未到货；
- 到货未验收；
- 订单付款和结算进度；
- 物料当前位置；
- 各区域可用库存；
- 借入、租赁和待归还清单；
- 损坏、遗失和差异清单；
- 商家履约与异常；
- 预算与实际采购差异。

## 10. 开发计划

### P0：模型与基础词典

- 定义需求、报价、订单、收货和物料移动模型；
- 定义物料分类、单位和位置；
- 定义采购与资金流水关联；
- 定义订单和到货状态机；
- 建立异常场景样本。

### P1：采购与物料 MVP

- 创建采购需求；
- 指定采购人和截止时间；
- 记录下单、付款和垫付；
- 记录到货、验收和直接交付位置；
- 物料入库、领用、调拨和退回；
- 查看当前位置和可用数量；
- 附件与备注。

### P2：供应商与结算

- 报价比较；
- 多次付款和多次到货；
- 退货退款；
- 订金、尾款和押金；
- 租赁和借用归还；
- 商家履约和异常记录。

### P3：自动化与优化

- 小票和报价单识别；
- 自动生成物料明细；
- 根据历史活动推荐数量；
- 缺货和延迟预警；
- 自动匹配订单、付款、到货和退款；
- 供应商历史表现分析。

## 11. 验收标准

- 一次采购可以由多个不同人员分别完成各环节；
- 支持先买后补录和直接送到使用区域；
- 支持多次付款、多次到货和部分退货；
- 能查看物料当前位置、保管人和可用数量；
- 能列出全部待归还租赁和借用物品；
- 采购支出、垫付、退款和商家结算可正确关联；
- 数量差异和订单异常有明确待处理状态。
