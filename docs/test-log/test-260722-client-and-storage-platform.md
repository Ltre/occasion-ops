期望：PWA 和微信小程序可访问同一服务端；附件默认进入国内云对象存储；业务代码不直接依赖厂商 SDK。

状态：待验证。

### 场景 3：未来开发 Android/iOS

期望：原生客户端复用 API 契约、领域类型和场景测试，不重新定义资金规则。

状态：待验证。

### 场景 4：更换对象存储厂商

期望：通过 Provider 适配和迁移流程切换；对象键、哈希、权限和业务关联可验证。

状态：待验证。

### 场景 5：未配置跨区域复制

期望：系统不会自动把中国大陆附件复制到海外，或把海外附件复制到中国大陆。

状态：待验证。

## 权限、安全与审计测试

文档必须明确：

- 附件默认私有；

文档必须明确：

- 客户端上传和资金提交都使用幂等机制；
